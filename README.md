Entry for the make.fun bounty [The Meeting That Should Have Been One Line](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c) ($2).

`main.ts` writes a single sentence — the one line that could have replaced an entire pointless meeting — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/`), with no trailing newline. The line is validated against the gate (1–200 characters, single line, not only whitespace) before it is written.

Entry: "This meeting could have been an email, but the email would have been ignored, so instead twelve people are ignoring each other in person." (137/200 characters)
